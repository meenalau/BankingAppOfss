oj-flex / oj-flex-item — JET's responsive 12-column-equivalent flex grid, wrapping the form and table sections

Responsive column sizing using oj-sm-12 oj-md-6 style classes — so on mobile it stacks full-width,
 on tablet/desktop it splits into columns

A responsive table/form arrangement: form fields side-by-side on desktop, 
stacked on mobile — visibly different from the "free" NavDrawer responsiveness, actually authored by you in this view

A locale dropdown (oj-select-single) with 2–3 locales (e.g. English-India, English-US, Hindi-India)
A Date Opened column/field, since date formatting makes the locale switch visually obvious (currency alone can look similar across locales)

Converters (balanceConverter, dateConverter) rebuilt reactively whenever the locale changes, 
using JET's oj.Config.setLocale() + a page reload of the config
 (JET requires this — locale isn't hot-swappable per-component, it's app-wide)

 JSON.parse() — JSON string → JavaScript object

        var jsonString =  '{"customerId":101,"name":"Meenal","email":"abc@gmail.com"}';

Then:var customer = JSON.parse(jsonString);

    Now customer becomes a JavaScript object:  

    customer.customerId
    customer.name
    customer.email

    Purpose:    Convert JSON text → JavaScript object so JavaScript can work with the data.
